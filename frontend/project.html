How the forecast is made, from public records to a live API

A binary classifier predicts whether a NYC apartment building gets a class B or C HPD violation in the next 6 months. Data is cleaned locally and stored in Google Cloud Storage. Training is tracked in MLflow, the model is served by FastAPI on Cloud Run, and both pages of this site call that API from the browser.

Pipeline and results

A model that beats the obvious rule, on data it never saw

Trained on every NYC building's record before May 2025, tuned on Nov 2025, then tested on May 2026: 162,997 buildings, of which 14% really got a B/C violation. The numbers below come live from GET /model.
