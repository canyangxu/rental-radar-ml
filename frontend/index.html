    How it works

    A model trained on every NYC building's record, tested on six months it never saw

    The pipeline, the test results against simple rules, and a form to send your own request to the model API are on the project page.

    See how the forecast is made →

    Limits. This is a forecast from public records, not an inspection. Inspections follow tenant complaints, so buildings whose tenants complain less can look safer than they are. Use it to decide what to ask, never as the only reason to rule a building in or out.
